Online-Mind2Web's 300 live-web tasks on agent-env's own browser, once per arm: Browser Use over CDP, and Claude Code with Playwright MCP.

# Online-Mind2Web

The tasks are [Online-Mind2Web](https://github.com/OSU-NLP-Group/Online-Mind2Web)'s, from the Hugging Face dataset
[`osunlp/Online-Mind2Web`](https://huggingface.co/datasets/osunlp/Online-Mind2Web) at revision
`eacad896a84dc5b65e29b0b06e4699ab0544d701` (CC-BY-4.0), generated by `agentenv_benchmarks.online_mind2web`. Each runs
on the live site it names.

## Run

```bash
agent-env run online-mind2web --eval sample           # three tasks, one per level, on each arm
agent-env run online-mind2web --eval tools            # all 300 with Claude Code and Playwright MCP
agent-env run online-mind2web --eval cdp              # all 300 with Browser Use over CDP
agent-env run online-mind2web --eval tools --agent codex
agent-env run online-mind2web --task tools-d71be72aa25c3eab8eea47a0e60382e2
```

The agents need a model endpoint (`[model]` in agent-env's config). A run without `--eval` or `--task` runs every eval.

## What every task does

| Step | What it does |
| --- | --- |
| `browser` | Deploys agent-env's `chromium` alone, headful, set once for every arm: a 1280×800 window, a blank start tab, dialogs accepted, location and notifications denied, en-US, UTC. |
| `setup` | Records, in the run's own record (`script_results.setup`), the dataset row and revision the task came from and the browser as deployed: its Chromium build, `mode`, clock and window. |
| `record` / `end` | Records the browser's screen for the whole run. |
| `agent` | Deploys the arm's agent. On `cdp`, `connect` hands Browser Use a CDP address to the browser, hiding its tools. On `tools`, Claude Code gets the browser's MCP, with only Playwright MCP's `browser_*` tools shown. |
| `task` | Prompts the agent with `Go to {website} and {task}`. Its final answer is the prompt's response, `answer`. |

Grading (WebJudge), the result export and results per arm come later; until then a run records each agent's answer,
trajectory, screen recording and the browser's action log.

## Arms

| Arm | Eval | Agent | Way in |
| --- | --- | --- | --- |
| `cdp` | `cdp` | Browser Use | its own CDP connection to the browser |
| `tools` | `tools` | Claude Code | Playwright MCP's `browser_*` tools, attached to the same browser |

`--agent` runs another agent on an arm: Codex on `tools`, or a Stagehand agent on `cdp` once it exists.

Some sites block datacenter addresses or automated browsers. agent-env's pre-flight sweep from an AWS VM and from
Modal found 21 tasks on 9 sites blocked in both: apartments.com, petfinder, imdb, backcountry, microcenter,
boardgamegeek, marriott, uniqlo and ticketmaster. They stay in the benchmark, and a run there counts as a failure.
